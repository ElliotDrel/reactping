A few quick answers.

Who gets the notification?

You do, when someone else reacts to a message you wrote. Your own reactions don't trigger a DM.

Can my team use it?

Yes. Each person connects their own Slack account. Connect in each workspace where you want notifications; DMs stay in that workspace.

Does it need admin approval?

Only if your workspace requires it. Ask an admin to approve ReactPing, then connect. Enterprise Grid installs aren't supported.

Is it free?

Yes. Add ReactPing to Slack and start using it.

Will it catch every reaction?

Notifications are best effort. Missed reactions aren't replayed.
